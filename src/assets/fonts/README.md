# ABWA World — Local Font Directory

Place any client-supplied premium typefaces (such as `.woff2`, `.otf`, or `.ttf`) in this directory.

## Embedding and Licensing Checklist
1. Verify web embedding rights under the typeface license before adding files.
2. Integrate via `next/font/local` in `src/app/layout.tsx`.
3. Preserve fallback font stacks (`Inter, system-ui, -apple-system, sans-serif`).
